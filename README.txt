CourseApp Documentation

1. OVERVIEW
CourseApp is a Single-Page Application (SPA) designed to manage academic courses and track credit units in one place without page reloads.
The app organizes academic progress. Users input a course Title, Code, and Units to generate a summary of their workload. It distinguishes between new and returning users based on stored data.

2. FEATURES
Smart Greetings: It changes from "Welcome" to "Welcome Back" once data is saved.

Live Stats: It automatically calculates total courses and total credit units.

Recent Activity: It displays a list of the 3 most recently added courses.

Persistent Data: It saves information to the browser's LocalStorage so data remains after a refresh.

Full Management: Users can add, view, edit, and delete courses.

3. User Guide
Dashboard: View the summary and the latest 3 entries.

Add Course: Use the form to enter new course details.

Manage List: View all courses to edit or remove them.

4. Data Privacy
All data is stored locally on your device. No information is sent to external servers.
